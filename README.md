# Espacial Natal 🎄🚀

Jogo de temática espacial e natalina desenvolvido na **Godot Engine**. Projeto de estudo de desenvolvimento de jogos (game dev), com lógica em GDScript e efeitos visuais em GDShader.

## 🧰 Tecnologias

- [Godot Engine](https://godotengine.org/)
- GDScript / GDShader

## ▶️ Como abrir

1. Instale a [Godot Engine](https://godotengine.org/download).
2. Abra a pasta do projeto (`jogo/`) na Godot.
3. Execute diretamente pela própria IDE (botão *Play*).

## 📁 Estrutura

- `jogo/` — projeto principal do jogo
- `jogo5/` — versão/iteração do projeto
